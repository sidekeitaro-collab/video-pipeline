# Privacy Policy

**Last updated: 2026-07-04**

## Overview

This application ("App") automates short-form video creation and publishing to social media platforms. This policy explains how we handle user data.

## Data We Collect

- **Account credentials**: OAuth tokens for platform access (stored locally, never shared)
- **Content metadata**: Video titles, descriptions, and tags generated during the pipeline
- **No personal data from third parties**: We do not collect or store data from viewers

## How We Use Data

- OAuth tokens are used solely to publish content to authorized accounts
- Generated content metadata is used only for the publishing workflow
- No data is sold, shared, or used for advertising

## Data Storage

- OAuth tokens are stored locally on the operator's device in encrypted format
- No data is stored on external servers beyond what is required by platform APIs

## Third-Party Services

This App uses the following APIs subject to their respective privacy policies:
- Anthropic Claude API (script generation)
- ElevenLabs API (voice narration, via Creatomate integration)
- Creatomate API (video rendering)
- Pexels API (stock background footage)
- YouTube Data API (content publishing)
- TikTok Content Posting API (content publishing)
- Instagram Graph API (content publishing)
- X API (content publishing, optional)

## User Rights

Users may revoke platform access at any time through their respective platform settings.
